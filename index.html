01 / THE IDEA

From a real object
to a phone screen.

Our project joins four simple steps into one learning experience.

01
▱

Show an object

We place cotton, scrap paper, a pencil, or another sample where the camera can see it.

02
◉

Capture an image

A USB webcam sends the live image to the Raspberry Pi 5.

03
⌘

Make a prediction

Our Python and OpenCV-based model chooses rubbish, not rubbish, or empty.

04
▣

View it on a phone

A phone on the same Wi-Fi can show the result and an in-page alert when a confident detection is made.

ⓘ

What “AI” means here: The model has learnt patterns from training photos. It makes a prediction; it does not understand whether an object should actually be thrown away.

02 / THE BUILD

Simple technology.
A clever connection.

▣Processing

Raspberry Pi 5

The small computer runs our Python code, receives camera images and makes predictions using a trained model.

◎Vision

USB webcam

The camera captures the scene. Keeping its angle and lighting consistent helps the model.

⌘Software

Python + OpenCV

Our image-processing and machine-learning code classifies examples using the photos we collected.

▤Connection

Phone web page

The Raspberry Pi serves a page that can be opened on a phone on the same local Wi-Fi network.

05 / WHAT WE LEARNT

Good ideas still
have limitations.

Being open about what does not work yet is part of being a good inventor.

01

AI can be uncertain

Some test predictions have shown only around 50–70% confidence. A confident answer can also be wrong.

02

The surroundings matter

Lighting, angle, backgrounds and unfamiliar rubbish can change the prediction.

03

It cannot collect rubbish yet

The current proof of concept does not drive, open a door, vacuum rubbish or automatically pick things up.

04

Phone alerts have limits

The prototype uses a local phone web page. Alerts appear in the page when it is open; these are not background push notifications.

07 / QUICK QUESTIONS

Curious? We have answers.

Does the robot really use artificial intelligence?+

Yes. We trained an image classifier with labelled sample photos. The model uses the patterns it learnt to predict one of three categories.

Does it pick up rubbish already?+

Not yet. Our working goal for this stage is recognition and sharing the result with a phone. Physical collection is a future project.

Is it always correct?+

No. Some predictions are uncertain or incorrect. Different objects and lighting can make recognition harder. We need better training data and proper testing.

Is the QR-code website the phone controller?+

No. This public webpage explains our school project. The actual camera/phone controller is a separate local application running on the Raspberry Pi, accessible only to devices on its network.

What is a proof of concept?+

It is an early demonstration that tests whether the main idea is possible, before building a complete and reliable product.
